# POS Thermal Receipt

Formats Point of Sale receipts for an 80 mm thermal paper roll.

## Install

1. Update the Apps list in Odoo.
2. Install **POS Thermal Receipt**.
3. Open the relevant POS configuration and configure its receipt printer in
   **Connected Devices** (via an IoT box for a network/USB thermal printer, if
   applicable).
4. In the printer driver, select **80 mm** paper and set margins to **None**.

The addon controls receipt layout only. It does not install printer drivers or
create a printer connection.
