POS Register Pool

Allows salespeople to choose an available POS register and keeps that register exclusively assigned to them until the POS session is closed.

  • Supports a shared pool of registers, such as Register 1 to Register 7.
  • Prevents another Odoo user from opening an occupied register.
  • Shows the active salesperson and their initial in the register list.

Each salesperson must use their own Odoo user account.
